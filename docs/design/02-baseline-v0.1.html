00 · 目录与规则

<素材库根目录>\ ├─ 01_深空\ 数字前缀只用于排序 │ ├─ M42_猎户座大星云\ │ │ ├─ 成片\ 成片进画廊 │ │ ├─ 原始\ FITS / RAW，可空 │ │ └─ 处理\ 工程与中间图，可空 │ └─ IC434_马头星云\ ... ├─ 02_星野\ │ ├─ 银河\ │ │ └─ 2026-06-16_冷湖\ 一次拍摄一个文件夹 │ ├─ 星轨\ │ ├─ 延时\ 视频与序列帧 │ └─ 其他\ 彗星、流星雨 ├─ _收件箱\ 新素材先落这里 ├─ _dwarf mini校准场\ bias / dark / flat / 暗场库，保持原样 └─ _历史记录\ 素材库历史记录.csv
扫描解析
文件名 + 文件夹共同提供字段
文件名规则 YYYY-MM-DD_目标或类型_设备_final_序号.ext；设备取值 DWARFMINI / CANON / PHONE；星野类型取父文件夹（银河 / 星轨 / 延时 / 其他）；地点取拍摄文件夹后缀，缺失记「未标注」。
读写边界
扫描只读，整理必须手动触发
扫描、生成缩略图、播放视频都不改原文件；移动 / 重命名只在用户点「整理」或保存地点时发生，全部经统一文件操作层，写操作日志，删除进回收站。

重命名规则

  • 星野：改地点保存后，文件夹由 日期_旧地点 改为 日期_新地点；日期不可通过地点字段修改。
  • 深空：地点只写数据库，不动物件；改目标中文名时重命名目标文件夹，编号保持不变。
  • 地点中的 \ / : * ? " < > | 替换为 -，去掉首尾空格；空地点写「未标注」。
  • 目标文件夹已存在时追加 _2、_3；重命名失败（占用 / 权限）回滚字段并提示。
  • 成功后同步更新数据库路径、缩略图缓存键与 change_log，并支持一次撤销。

打开文件夹

  • 深空详情右上「打开成片文件夹」→ 目标/成片。
  • 星野组头与记录卡「打开文件夹」→ 该次拍摄目录。
  • 查看器「打开文件夹」→ 资源管理器中定位并选中当前文件。
  • 路径不存在时提示「重新定位」，不静默失败。

bg #05070e · panel #0b1220 · cyan #6ee7ff · violet #a78bfa · amber #f5c26b · rose #fb7185 · green #5eead4
缩略图
3 档尺寸，WebP 缓存
124px 胶片带 / 320px 卡片 / 1600px 预览；Dwarf 白条按 strip_ratio 裁掉；缓存放 %APPDATA%\AstroArchive\thumbs，可删重建。
数据库
SQLite + 迁移
%APPDATA%\AstroArchive\archive.db；每次启动检查 schema 版本；所有写操作走事务。
文件操作
统一入口 + 回收站
扫描只读；移动 / 重命名 / 删除只经由 fileService；删除进回收站；每次操作写 change_log，支持一次撤销。

04 · 阶段 1 验收

范围
骨架 + 扫描 + 首页 + 深空浏览
Electron + React + TS + Vite；SQLite schema v1；扫描 <素材库根目录>；缩略图生成；首页按 v1.3 落地。
验收
真实数据能跑通
首页数字与目录一致；4:3 目标卡与 16:9 星野横幅正确；增删一张成片重扫后反映；打开文件夹按钮可用；便携版双击即开。
本阶段不做：星野视频播放、导入收件箱、校准场拷贝、同步任务、统计页。这些放到阶段 2 之后，避免首版铺太大。
