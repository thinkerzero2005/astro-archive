01视觉基调

界面像一间关灯的暗房：背景接近黑，但不死黑；照片是唯一的高饱和区域；颜色只用来表达状态，不用于装饰。

Dark Room · 暗房感

让照片发光

底色 #05070e，面板 #0b1220，两者只差一个层级。面板靠 1px 低对比描边和极轻的内高光分层，不用重阴影。照片四周留 1px 内描边，避免深色吞掉边缘。

Signal Color · 状态色

颜色即含义

星青＝可点击 / 当前 / 已连接；暗紫＝信息与来源标记；暖金＝需要注意；玫红＝危险或失败；薄荷绿＝成功。同屏最多出现两种状态色，避免仪表盘感。

Quiet Interface · 安静

控件退后

主操作每屏只保留一个（同步 / 保存 / 开始）；其余按钮降为幽灵态。滚动时不出现悬浮工具栏，批量操作固定在列表底部。数字用等宽字形，避免跳动。

与线框的差异：结构、页面与信息层级完全沿用 v0.2，只补三件事——① 真实照片与缩略图；② 明确的字号 / 间距 / 圆角刻度；③ 悬浮、选中、来源标签与进度等状态的具体样式。

一套 5 色状态 + 4 级中性色 + 5 档圆角 + 6 级字号，够用且不容易失控。所有页面共用这套刻度。

2.5图片处理与动效

Image Treatment

圆角 9px；1px 内描边 rgba(255,255,255,.09)；分日期缩略图按原比例、不裁切，仅卡片封面裁切填充。悬停放大 1.045，时长 0.5s。

Motion · 克制
  • 页面切换：120ms 淡入 + 4px 上移；不做横向滑动。
  • 抽屉：220ms cubic-bezier(.2,.7,.2,1) 从右滑入。
  • 悬停：边框提亮到 rgba(150,180,220,.22)，150ms。
  • 进度条：数值变化 300ms 缓动；不循环闪光。
  • 尊重「减少动态效果」系统设置，全部降为即时切换。

11落地说明

这一版是静态视觉稿，不含交互逻辑。开发时直接按下面的刻度落地，避免每个页面各写一套数值。

Layout
  • 基准窗口 1440×900，最小 1024×700。
  • 侧栏 204px（可折叠 56px），顶栏 56px。
  • 内容区左右留白 22px，模块间距 9–14px。
  • 首页主视觉 268px；后续页面不再出现大主视觉。
Assets
  • 本稿配图取自工作区真实成片（天文摄影照片\），仅作版式演示。
  • Dwarf 成片底部自带白色信息条：分日期缩略图按原比例显示并裁掉该条，首页主视觉与卡片封面仍裁切填充。
  • 天体名片正式版优先使用 NASA 公版图，需在右下角标来源与许可。
  • 图标统一 1.7px 描边、圆角端点，不混用实心图标。
States
  • 所有列表都要有：空态、加载骨架（>400ms）、错误行、选中行。
  • 危险操作二次确认，文案写清影响数量与是否可撤销。
  • 同步、拷贝、扫描必须可取消，且保留已校验文件。
Constraints
  • 深空与星野的统计口径分离，星野页面不出现累计曝光。
  • 颜色只用于状态；同屏状态色不超过两种。
  • 不使用大面积纯白、纯黑反差；夜间亮度优先。
