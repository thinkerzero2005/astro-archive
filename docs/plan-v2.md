# 星空摄影档案管理软件 · 后续开发计划 v2

> 状态：已完成，对应 0.3.1（2026-11）。本文件仅作历史记录，后续计划见仓库根目录 `ROADMAP.md`。

当前基线：v0.2.0，typecheck / 构建 / 单测 / 打包全部通过。以下为顺序执行清单，完成一步再进入下一步，每一步都可独立验收。

**执行原则**
- 真实素材库只读，所有写入测试使用临时库或只读副本。
- 数据库只做增量迁移，保留撤销与变更日志。
- 每一步结束运行 typecheck、相关单测与构建；不通过不进入下一步。

---

## 步骤 1：修复重扫覆盖手工值（P0）

**目标**：人工修正的曝光与「已核对」状态在重扫后不丢失。

**改动**
1. `files.ts`：核对保存时 `review_state` 写 `manual`（不再写 `ok`）。
2. `scanner.ts` upsert SQL 增加保护：
   - `exposure_source='manual'` 时保留旧 `total_exposure_s` 与来源；
   - `review_state='manual'` 时保留 `manual`，不重置为 `pending`。
3. 新增 `review:reset`：用 `watermark_text` 重新解析曝光与待确认原因，恢复为 `watermark` 来源；无有效值时归零并标待确认。
4. `ReviewDialog` 增加「待确认 / 已核对」切换，已核对行提供「恢复自动」。
5. 扩展 `scanner.test.ts`：核对 3600s → 重扫两次 → 数值与状态保持；恢复自动 → 回到 OCR 值。

**验收**
- 重扫后待确认数量、统计数字、人工曝光均不变。
- 恢复自动可重复执行，结果稳定。

---

## 步骤 2：颜色令牌化（主题前置，不改视觉）

**目标**：把散落的硬编码颜色收敛为 CSS 变量，为浅色主题做准备。

**改动**
1. 在 `styles.css` 定义语义变量：`--bg`、`--panel`、`--panel-2`、`--line`、`--text`、`--muted`、`--accent`、`--ok`、`--warn`、`--danger`。
2. 按页面逐步替换硬编码色值：首页、深空、目标详情、夜次、星野、统计、检索、收件箱、设置、弹窗。
3. 保持默认深色视觉完全一致。

**验收**
- 深色下逐页截图与改造前一致。
- `styles.css` 中不再新增硬编码背景/文字颜色。

---

## 步骤 3：主题与外观设置（FR-18）

**目标**：支持深色 / 浅色 / 跟随系统，并持久化。

**改动**
1. 设置项：`theme`、`accent`（6 套预设）、`reduce_motion`；写入 `settings` 表并同步 `localStorage`。
2. 启动时在首屏渲染前同步套用主题，避免闪屏。
3. 设置页新增「外观」分组：主题三选一、强调色色板、减少动效、恢复默认。
4. 浅色变量表与状态色适配；减少动效时关闭过渡与动画。

**验收**
- 切换即时生效、重启保持；系统主题变化时 `system` 模式跟随。
- 六个主要页面浅色下文字、边框、图表清晰可读。

---

## 步骤 4：首页模块配置（FR-18 收尾）

**目标**：首页模块可显隐、可调整顺序。

**改动**
1. 模块：最近作品、深空目标、星野入口、夜次、统计条。
2. 设置页或首页提供显隐开关与上/下移。
3. 配置写入 `settings`，提供恢复默认。

**验收**
- 刷新与重启后配置保持；全部隐藏时显示空状态提示。
- 若审核时希望缩小范围，本步骤可整体延后，不影响其他步骤。

---

## 步骤 5：建库向导（FR-01）

**目标**：首次建库安全、可预期。

**改动**
1. 选择目录后校验：存在性、可写性、是否为空、是否误选源素材目录。
2. 非空目录明确提示并二次确认；不删除、不覆盖已有内容。
3. 自动创建缺失目录：`01_深空`、`02_星野`、`_收件箱`、校准场目录。
4. 完成后显示目录结构与下一步入口（导入 / 同步 / 扫描）。
5. 补充空目录、非空取消、只读目录三类测试。

**验收**
- 新目录一键得到标准结构；非空目录取消后无任何改动。

---

## 步骤 6：导入增强（FR-02 / FR-17）

**目标**：除 `_收件箱` 与 Dwarf 同步外，支持拖拽和普通文件夹导入。

**改动**
1. 拖拽导入：preload 暴露 `webUtils.getPathForFile`，拖入文件/文件夹复制到 `_收件箱/<批次>/`，源文件不动。
2. 普通文件夹导入：选择目录后递归收集支持格式，复用暂存、进度、错误汇总。
3. 去重口径：文件名 + 大小 + mtime；重复项跳过并列入报告。
4. 收件箱「暂不整理」：移动到 `_收件箱/_暂不整理/`，不参与统计；提供移回入口。

**验收**
- 拖入 100 个文件有完整进度与失败清单，源目录不变。
- 重复导入不产生副本；暂不整理在重扫后仍保持。

---

## 步骤 7：检索增强与批量编辑（FR-15）

**目标**：补齐器材、目标、版本三个维度与排序。

**改动**
1. `SearchParams` 增加 `targetId`、`rigId`、`versionState`。
2. 检索页增加对应筛选，排序支持日期 / 评级 / 曝光 / 文件大小。
3. 网格与表格切换；多选后批量评级、批量备注。
4. 批量操作复用现有更新与撤销链路。

**验收**
- 组合筛选结果与统计口径一致；批量编辑可一次撤销。

---

## 步骤 8：夜次记录卡与日历（FR-11A / FR-12 / FR-21）

**目标**：记录卡字段完整，夜次可按日历浏览。

**改动**
1. 记录卡展示月相、Bortle、视宁度、天气备注。
2. 新增 `post_process` 字段（schema v8）并在夜次编辑中填写。
3. 汇总展示当夜器材、镜头、单张曝光、ISO/Gain、张数、累计曝光。
4. 延时补充序列帧数、成片时长、帧率。
5. 夜次页增加「列表 / 日历」切换：月历格子显示夜次数与分类色点，点击筛选列表。

**验收**
- 旧数据升级后字段为空但不报错；日历与列表数量一致。

---

## 步骤 9：FITS 头与在线天体名片（FR-04 / FR-11）

**目标**：补齐原始帧时间解析与天体资料在线补充。

**改动**
1. 新增 `fits.ts`，解析 `DATE-OBS`、`EXPTIME`、`GAIN`、`FILTER`、`OBJECT`。
2. 缺少 `shotsInfo.json` 时用首帧时间推算夜次；优先级：FITS 头 > shotsInfo > 文件名 > 文件夹 > mtime。
3. 天体名片联网补充：中文维基优先、英文维基兜底、最终回退内置资料；摘要与首图缓存到数据目录。
4. 设置项「允许联网获取天体资料」；失败显示重试，不阻塞页面；只发送目标名称。

**验收**
- 最小 FITS 头样本解析正确，夜次推算与文件名冲突时按优先级取值。
- 断网时名片显示缓存或内置资料。

---

## 步骤 10：增量扫描、回归与 0.3.0 发布

**目标**：性能与发布收尾。

**改动**
1. 扫描以「路径 + 大小 + mtime」为指纹跳过未变化文件；保留全量重扫入口。
2. 进度区分解析 / 缩略图 / 水印识别阶段，可取消。
3. 补回归测试：主题持久化、建库、导入去重、检索、FITS、恢复自动。
4. 版本升至 0.3.0，更新版权信息，打包并在隔离库走完整流程。

**验收**
- typecheck、构建、全部单测通过。
- 隔离库实测：建库 → 导入 → 识别 → 核对 → 重扫 → 检索 → 统计，无报错。
- 真实库仅做只读扫描验证。
